# yummzi-site

The public pages for the Yummzi iPhone app: home, support and privacy policy.
Served by GitHub Pages at https://mahmoudeidarous.github.io/yummzi-site/ (publish with `sh publish.sh`).

The support form sends messages to the `suggestions` table in the Yummzi Supabase project
(with the public publishable key; visitors can add a message but never read one).
